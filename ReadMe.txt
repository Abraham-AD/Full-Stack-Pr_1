This project is a full-stack web application built using Laravel (backend) and React with Vite (frontend). It provides a complete authentication system and a secure dashboard interface for managing users. The backend exposes a RESTful API protected by Laravel Sanctum, while the frontend consumes these API endpoints using Axios, manages global authentication state via React Context, and handles routing with React Router.

The application allows users to sign up, log in, log out, and access protected pages. Once authenticated, users can view and manage data through routes that require a valid API token. All protected operations (like retrieving users, creating new users, updating profiles, and deleting users) are accessible only after successful authentication. The frontend automatically attaches the stored Bearer token to each API request, ensuring secure communication with the backend.

Laravel handles validation, user creation, token generation, and CRUD operations, while React provides a fast, interactive interface that updates without full page reloads. With clearly separated concerns—backend for business logic and API services, frontend for UI rendering and user experience—the project demonstrates a modern, scalable, and professional full-stack architecture.
